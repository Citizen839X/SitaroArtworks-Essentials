SitaroArtworks™ Essentials — Vector Brush Set

A versatile, high-quality collection of vintage vector brushes originally created in 2012 for Adobe Illustrator and fully extracted into clean SVG vectors. Designed for digital artists, illustrators, and graphic designers looking for organic, hand-drawn vector elements.

🎨 Overview

This brush set of 21 offers a wide variety of scalable stroke styles and decorative elements, including:

Hatching & Cross-Hatching: Ideal for shading, sketch effects, and vintage engravings.

Textured & Rough Strokes: Perfect for rough contours, ink marks, and natural media simulation.

Organic & Decorative Paths: Includes branches, flames/waves, chains, tire tracks, and ribbon banners.

All brush assets are provided as clean, fully editable SVG vector paths (<Path>, <Compound Path>, and <Group>).

📦 File Format & Compatibility

Format: Scalable Vector Graphics (.svg)

Compatibility:

Compatible with VectorCraft, Inkscape, Adobe Illustrator (CS3 through CC), Affinity Designer, and any vector editor capable of importing or parsing SVG paths.

Can be used directly as vector assets or integrated into custom brush engine presets.

🚀 Installation & Usage

For VectorCraft / Inkscape / General SVG Editors

Import or open SitaroArtworks_BrushSet.svg into your workspace.

Copy/paste individual vector elements or add them to your asset/symbol library.

Apply color, scale, or transform the paths freely without quality loss.
